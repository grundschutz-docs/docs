# Hosted version

**Not live yet.** No domain, no deployment — this describes the plan, not
something that exists today.

## What this repo is

This repo is the real, complete version — not a teaser for something
better. MIT-licensed, fully self-hostable (Docker/systemd), no feature
held back to make a paid or hosted tier look better by comparison.

## What's planned

A hosted version on my own domain, with richer presentation than this
repo ships — e.g. security level and effort shown as real, hoverable
badges instead of inline text. It stays **free to use for everyone**, no
paywall, no access gate. The only thing it doesn't offer is self-hosting:
its extra layer's source stays closed.

## Self-hosting on request

If you have a genuine reason to want to self-host the hosted-only
features, email me: bruno.deanoz@protonmail.com. That's a case-by-case
conversation, not an automated process — but the door isn't closed.

## Why this file exists

If the hosted version ever ends up visibly ahead of this free repo, that
needs to be said plainly here, not happen quietly. Otherwise this project
would be doing the exact thing it criticizes elsewhere: claiming openness
while delivering less than it implies.
